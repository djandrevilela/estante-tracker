# estante-tracker
PWA para seguir BD, manga e comics: descobre séries (Marvel, DC, manga via AniList), marca capítulos e volumes como lidos, guarda tudo localmente no teu dispositivo e recebe notificação quando sai lançamento novo do que segues. Instalável em Android e iOS, disponível em PT e EN. 100% gratuito, sem contas nem anúncios.
